# Requerimientos Funcionales

- El sistema debe permitir capturar en tiempo real la pantalla compartida por el usuario.
- El sistema debe detectar y localizar todos los rostros visibles en la pantalla compartida.
- El sistema debe mostrar al usuario todos los rostros detectados para su visualización previa.
- El sistema debe permitir al usuario seleccionar los rostros que serán analizados durante la sesión.
- El sistema debe permitir al usuario asignar un nombre a cada rostro seleccionado.
- El sistema debe guardar la información de los rostros seleccionados para su uso durante la sesión.
- El sistema debe detectar en tiempo real las emociones faciales de los rostros seleccionados.
- El sistema debe visualizar en tiempo real las emociones detectadas mediante representaciones gráficas intuitivas (por ejemplo, íconos, colores, o barras de emociones).
- El sistema debe permitir al usuario iniciar y detener la detección de emociones.
- El sistema debe registrar el tiempo de inicio y finalización de cada sesión.
- El sistema debe generar un reporte detallado al finalizar la sesión con la siguiente información por rostro:
    - Porcentaje de duración de cada emoción.
    - Número de veces que se detectó cada emoción.
    - Cambios emocionales drásticos (ej. de felicidad a tristeza) y su momento.
    - Gráfica visual de emociones en el tiempo tipo sparklines.
- El sistema debe permitir exportar el reporte en formato PDF.
- El sistema debe guardar los reportes generados para su posterior consulta.
- El sistema debe permitir a los usuarios autenticarse exclusivamente mediante sus cuentas de Google.
