sequenceDiagram
    title Detección emocional en tiempo real (post-selección de rostros)

    actor Usuario as Usuario
    participant Web as Aplicación Web
    participant Plataforma as Plataforma de videollamadas
    participant API as Backend API
    participant Servicio as Servicio de Emociones
    participant DB as Base de Datos

    %% Inicia tras la selección y guardado de rostros
    Usuario->>Web: Clic en "Iniciar detección emocional"
    activate Web

    Web->>DB: Solicita rostros seleccionados y sus coordenadas
    activate DB
    DB-->>Web: Retorna rostros autorizados para seguimiento
    deactivate DB



    %% Bucle de detección continua
    rect rgb(230, 245, 255)
        loop Cada X segundos
            Web->>Web: Captura un frame de la pantalla compartida

            Web->>Web: Recorta imágenes de rostros guardados

            Web->>API: Envía imágenes recortadas con IDs de usuario

            activate API
            API->>Servicio: Procesa rostros y detecta emociones
            activate Servicio
            Servicio-->>API: Devuelve emociones detectadas por rostro
            deactivate Servicio

            API-->>Web: Devuelve emociones actuales
            deactivate API

            Web->>Web: Actualiza UI con emociones (íconos, gráficas)
        end
    end

    Usuario->>Web: Clic en "Finalizar detección"
    Web->>Usuario: ¿Está seguro de finalizar?
    Usuario-->>Web: Confirma finalización

    Web->>API: Solicita cierre de sesión emocional
    API->>DB: Guarda estado final, emociones y timestamp de cierre

    deactivate Web
